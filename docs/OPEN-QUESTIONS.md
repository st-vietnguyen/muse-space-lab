# Open Questions — MuseSpace

Product decisions. OQ-01 to OQ-08 were proposed by AI in an earlier HLD draft and all decided using the default proposal (2026-11-11). OQ-09 to OQ-23 come from the architecture review (Tech Lead × Product Manager × Solution Architect, 2026-11-13) and were all decided using the default proposal (2026-11-18), with OQ-19 adapted (see its Decision). Related documents mark each decision with `(OQ-xx)`.

How to use: fill in the **Decision** column, update the related documents, then set the status to `Decided`. No roadmap may be generated while OQ-01 is open. Other items may be decided later, but before the Plan step of the related feature (see the "Related OQs" column in `ROADMAP.md`).
